DockPin

Keeps the macOS Dock on your main display. No more Dock jumping to whichever monitor your pointer touches.

Download for Mac Source on GitHub

Free and open source · macOS 13 or later · Apple silicon and Intel · Notarized by Apple

~2 MBof memory

Install

  1. Download DockPin.dmg and drag DockPin to Applications.
  2. Open DockPin once. From then on it starts at every login.
  3. Allow it in System Settings > Privacy & Security > Accessibility.

Or with Homebrew:

brew tap indapublic/dockpin https://github.com/indapublic/dockpin
brew trust --formula indapublic/dockpin/dockpin
brew install indapublic/dockpin/dockpin
brew services start dockpin

How it works

macOS moves the Dock to another display when the pointer pushes against that display's bottom edge, or its side edge if the Dock is on the side. DockPin ignores the pointer's movement in a thin 4 pt band along that edge of every display except the main one. The cursor still moves normally, but the Dock never sees the push.

If the Dock ends up elsewhere anyway, for example after you plug in a monitor, DockPin brings it back to the main display. The main display is the one you mark as main in System Settings > Displays.

Why it needs Accessibility

Filtering pointer events is something macOS only allows apps with the Accessibility permission to do. DockPin only looks at where the pointer is. It never connects to the network, collects nothing and stores nothing, and its whole source is one C file you can read.

Questions

How do I quit or remove it?

Turn DockPin off in System Settings > General > Login Items, or run /Applications/DockPin.app/Contents/MacOS/DockPin --unregister, then move DockPin to the Trash. With Homebrew: brew services stop dockpin and brew uninstall dockpin.

Does it work with the Dock on the left or right?

Yes. DockPin follows the Dock's position and guards the matching edge.

Will I lose the permission after an update?

No. Releases are signed with the same Developer ID, so macOS keeps the Accessibility permission across updates.

Can I still move the pointer between monitors?

Yes. Edges that border another display are left alone, so the pointer crosses over as usual.
